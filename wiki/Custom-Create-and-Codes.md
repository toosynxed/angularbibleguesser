# Custom, Create & Codes

Ways to build your own games or play someone else’s verse set.

## Custom Mode

**Online Modes → Custom**

Configure a random game:

| Setting | Options |
|---|---|
| Rounds | 1–50 |
| Context | 0–250 |
| Time limit | Optional (per round) |
| Books | Include / exclude Bible books |

Verses are chosen randomly from your selected books. Scoring matches other typed-guess modes — see [[Scoring]].

## Create Mode

**Online Modes → Create**

* Hand-pick the verse for each round
* Set context, time limit, and other options
* Generate a share code / link
* Optionally **Save to My Sets** so it can appear on the [[Verse-Board]]

## Play via code

**Online Modes → Upload Via Code** (or open a shared `/game/...` link)

Load a fixed verse list and settings from:

* A **short share code** (quick share from results or Create Mode)
* A **permanent game link**
* A Verse Board set’s code

Shared games use the same scoring as Custom when you play them.

## Sharing after any game

From the results screen you can:

* Share a **short code** for friends to paste (UI notes a short lifetime — treat as temporary)
* Share a **permanent link**
* **Copy Results** as an emoji scorecard
