# Daily Challenge

A shared five-verse challenge that resets each day.

## How to start

Home → **Daily Mode** → Play Daily

## Rules

* **5 verses** — the same set for every player that calendar day
* Context locked at **250** (full surrounding context for the challenge)
* No time limit
* One completion per day for streak purposes
* Uses standard [[Scoring|points and stars]]

## Streaks & calendar

* Completing consecutive days builds a **streak** (🔥)
* Completed days show as ✅ on the calendar
* After you finish, a countdown shows time until the next day’s challenge
* Streak UI is intended for **signed-in** (non-guest) accounts

## Leaderboards

From home **Leaderboards**, Daily tracks include:

* Daily streak
* Daily average score
