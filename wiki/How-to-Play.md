# How to Play

## The goal

You are shown Bible text with **one verse highlighted**. Guess that verse’s:

1. **Book**
2. **Chapter**
3. **Verse number**

Closer guesses score more points. Matching book / chapter / verse also earns **stars**.

## Basic flow

1. Open [Better Bible Guesser](https://better-bibleguesser.web.app)
2. Pick a mode from the home screen (or open **Online Modes** / **Quest Mode**)
3. Read the passage and the highlighted verse
4. Enter your guess with either:
   - **Scroll Picker** — pick book, chapter, and verse from lists
   - **Classic Input** — type a reference like `John 3:16`
5. Submit, review the round feedback, then continue to the next round
6. At the end, check your results (and share or replay if you want)

## On-screen tools

| Control | What it does |
|---|---|
| Context slider | Shows more or less surrounding verses (when the mode allows it) |
| Refocus | Jumps the view back to the highlighted verse |
| Timer | Appears when a time limit is set — running out scores 0 for that round |
| Next / See Results | Continues the game or opens the final summary |

## Accounts

* You can play as a **guest**
* **Sign in** (Google or email/password) to save stats, daily streaks, scrolls, cosmetics, and full multiplayer features
* Display names are limited to **15 characters**

## Sharing a finished game

After results, you can share the same verse set with friends via a **short code** or a **permanent link**. See [[Custom-Create-and-Codes]].
