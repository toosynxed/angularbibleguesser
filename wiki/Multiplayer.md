# Multiplayer

Play the same verse set at the same time as friends, then compare scores on the lobby leaderboard.

## How to start

1. Home → **Online Modes** → **Multiplayer Mode**
2. Set your **Display Name** (max 15 characters; locked to your account name if signed in)
3. **Create Lobby** or enter a **Lobby Code** to join
4. Wait in the lobby while the host configures the game
5. Host presses **Start Game** — everyone plays the same rounds

Signed-in players may see a short one-time tutorial the first time.

## Lobby

| Feature | Details |
|---|---|
| Lobby Code | Share this so friends can join |
| Host | Controls settings and starts the game |
| Settings (host) | Rounds, time per round, context (0–250), book selection |
| Waiting Room Mini-game | Non-hosts can play a click-the-moving-Scroll game while waiting (local high score) |
| Spectator link | Copy a live leaderboard link for people watching |

Inactive lobbies expire after about **30 minutes**. If the host leaves, host duties can move to another player. Getting kicked returns you home with an error.

## During the game

* Everyone gets the same seeded verses
* Scores submit each round
* The host can advance / skip waiting between rounds
* Final results show the lobby leaderboard

## Tips

* Sign in before creating a lobby if you want your name and cosmetics to stick
* Use the spectator leaderboard for classrooms or watch parties
* For solo practice with custom rules, use [[Custom-Create-and-Codes]] instead
