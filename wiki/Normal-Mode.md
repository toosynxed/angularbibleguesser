# Normal Mode

The classic Better Bible Guesser experience.

## How to start

Home → **Normal Mode**

## Rules

* **5 rounds** of random verses
* Context starts near **1** and can be adjusted mid-round (slider **0–250**)
* No daily lock — play as many games as you like
* Uses standard [[Scoring|points and stars]]

## Stats

Signed-in players track Normal Mode stats (games played and averages) from the home **Stats** panel.

## Tips

* Use a little context to get book/chapter clues without revealing too much
* **Refocus** if you scroll away from the highlighted verse
* Switch between Scroll Picker and Classic Input for whichever is faster for you
