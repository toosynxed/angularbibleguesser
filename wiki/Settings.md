# Settings

Home → **Settings**

Preferences are stored on your device (local storage).

## Options

| Setting | Purpose |
|---|---|
| Effects audio | Toggle sound effects |
| Game audio | Toggle game audio |
| High contrast | Stronger colour contrast for readability |
| Hide other player names | Privacy preference for multiplayer name display |
| Font scale | Roughly **0.85–1.4** |
| Theme | Dark / light |

You can save or reset settings from the settings page.

> Some preferences may apply more fully than others depending on the current build (for example audio hooks or multiplayer name hiding). If a toggle doesn’t seem to change anything, try refreshing after save.
