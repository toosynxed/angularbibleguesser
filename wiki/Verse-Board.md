# Verse Board

A community board of shared verse sets you can play.

## How to open

Home → **Verse Board** (best when signed in)

## What you’ll see

Each set listing can show:

* Set name
* Uploader’s display name
* When it was uploaded
* Number of rounds
* Times played
* **Start from Code** — loads that set as a shared game

Sets are ordered with popular / played sets surfaced from the community collection.

## Adding a set

Use [[Custom-Create-and-Codes|Create Mode]] and **Save to My Sets** to publish a set permanently. Playing a board set can increase its play count.
